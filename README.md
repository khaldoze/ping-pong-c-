# 🏓 Classic Ping Pong Game

A classic, fast-paced 2D **Ping Pong** game built from scratch using **C++** and the lightweight **[Raylib](https://www.raylib.com/)** library.

---

## ✨ Features

* **Smooth Physics:** Accurate ball bouncing dynamics and paddle collision handling.
* **AI Opponent:** Single-player mode with dynamic bot tracking.
* **Score Tracking:** Real-time on-screen scoring system.
* **Clean & Modular Code:** Easy-to-read, modern C++ implementation.

---

## 🎮 Controls

| Action | Key |
| :--- | :--- |
| **Move Paddle Up** |  `Up Arrow` |
| **Move Paddle Down** | `Down Arrow` |
| **Exit** | `Escape` |

---

## 🛠️ Built With

* **Language:** C++ (C++17 or newer recommended)
* **Graphics Library:** [Raylib](https://www.raylib.com/) (v4.5+)
* **Compiler:** GCC / Clang / MSVC
